# PillPal Patient Web

This is the front-end application for PillPal patients, built with React, Vite, and TypeScript.

## Getting Started

1. Navigate to the workspace root and run `npm install`.
2. Start the development server using Turborepo from the root (`npm run dev`), or start it locally from this directory:

```sh
npm run dev
```

## Build

To build the application for production:

```sh
npm run build
```
